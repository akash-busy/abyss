What this does and does not prove

How to read it

  • Code read only. No exploit was run and no live system was tested, so "confirmed" means confirmed by reading code.
  • Tachyon, Checkout, Frost and Falcon were read on POP-57, and Stream on release-2026-10-26, not master.
  • The radar places each finding in the first repo listed for it. Paths are relative to each repo.
  • Tags: Confirmed means traced through the code. Partly confirmed means exposure or impact depends on something unchecked. Re-read means the source was read a second time.

Not covered

  • nginx, firewalls, production environment values, log retention, and whether leaked keys still work.
  • Per-handler checks in the larger services were sampled, so more cross-tenant and injection cases probably exist.
  • No npm audit or govulncheck scan ran.
  • Rapid and the Tachyon side of stock reservation (AddInvTx) were not audited.
  • The migrate token and the e-way bill encryption key appeared in the audit's working output. Include them when rotating.
